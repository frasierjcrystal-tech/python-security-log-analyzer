## 📖 Project Overview

The Python Security Log Analyzer is a cybersecurity project that analyzes authentication log files to identify suspicious login activity.

The application scans log entries, detects failed authentication attempts, identifies repeated login failures, and helps security analysts investigate potential brute-force attacks or unauthorized access attempts.

This project demonstrates practical cybersecurity analysis using Python while applying incident response, log analysis, and security monitoring techniques.
